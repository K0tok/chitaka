# Читака - Каталог книг

Это веб-приложение представляет собой каталог книг с возможностью поиска, добавления в избранное и авторизации.

## Публикация на GitHub Pages

Для публикации этого сайта на GitHub Pages выполните следующие шаги:

1. Создайте новый репозиторий на GitHub или используйте существующий
2. Загрузите все файлы из этой папки в репозиторий
3. Перейдите в настройки репозитория (Settings)
4. Прокрутите вниз до раздела "Pages"
5. В поле "Source" выберите "Deploy from a branch"
6. В качестве ветки выберите "main" и в качестве папки "/ (root)"
7. Нажмите "Save"

Через несколько минут ваш сайт будет доступен по адресу:
`https://your-username.github.io/repository-name`

## Особенности реализации

- Сайт полностью статический и использует localStorage для хранения данных
- Все пути к ресурсам указаны относительно корня сайта
- Поддерживается адаптивный дизайн
- Реализованы страницы: главная, поиск, страница книги, избранное, профиль, вход и регистрация

## Структура проекта

- `index.html` - главная страница сайта
- `style.css` - стили для всего сайта
- `script.js` - основной JavaScript код
- `data/books.json` - данные о книгах
- `images/books/` - изображения обложек книг
- `pages/` - дополнительные HTML страницы
