# Читака - Многостраничный веб-сайт

## Описание
Многостраничный адаптивный веб-сайт "Читака" на чистом HTML, CSS и JavaScript (без фреймворков). 

## Структура проекта
```
/Читака
  /data
    books.json                  ← массив книг: id, title, author, description, shortDescription, genre, rating, cover
  /images/books/                ← обложки (загружаются вручную)
  /pages/
    index.html                  ← Главная (без авторизации)
    index-auth.html             ← Главная (с авторизацией)
    login.html                  ← Вход
    register.html               ← Регистрация
    search.html                 ← Поиск
    favorites.html              ← Избранное
    profile.html                ← Профиль
    book.html                   ← Карточка книги
  styles.css                    ← единый CSS
  script.js                     ← интерактивность (localStorage)
```

## Особенности
- Адаптивная вёрстка (от 320px)
- Семантический HTML
- Все данные — из `books.json` и локальных изображений
- Никаких внешних библиотек, CDN, API
- Код читаемый, с комментариями по блокам

## Интерактивность
- «Избранное»: клик по иконке → переключение между состояниями (серый ↔ красный), сохранение в `localStorage`.
- Оценка: можно выбрать рейтинг 1–5 (визуальные звёзды), сохраняется в `localStorage`.
- Мобильное меню: при <768px — скрытая навигация, раскрывается по клику на бургер.
- Переходы: все ссылки ведут на соответствующие HTML-файлы в `/pages/`.

## Запуск
Для запуска сайта необходим локальный сервер, так как используется fetch API для получения данных из JSON файла.
